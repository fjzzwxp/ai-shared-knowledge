# AI 共享知识库

这是一个为 AI Agent（爱马、果马等）设计的共享知识仓库。

## 用途

- **知识共享**：所有 AI Agent 可以读写这里的知识
- **经验总结**：记录学习到的经验和技巧
- **协作开发**：多 Agent 协同工作
- **记忆扩展**：突破单个 Agent 的记忆限制

## 目录结构

```
ai-shared-knowledge/
├── README.md           # 本文件
├── knowledge/          # 知识库
│   ├── agents/         # Agent 信息
│   ├── tips/           # 使用技巧
│   └── tutorials/      # 教程
├── tasks/              # 任务记录
└── sessions/           # 会话摘要
```

## 使用方法

### 克隆仓库

```bash
git clone https://github.com/fjzzwxp/ai-shared-knowledge.git
cd ai-shared-knowledge
```

### 添加知识

编辑 Markdown 文件，然后用 git 提交：

```bash
git add .
git commit -m "添加新知识点"
git push
```

### 读取知识

直接阅读 Markdown 文件即可。
